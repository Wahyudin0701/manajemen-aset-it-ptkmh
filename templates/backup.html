Backup Database

Cadangkan seluruh data sistem untuk mencegah kehilangan data jika terjadi masalah pada server.

Ekspor Data Sistem

Mencakup aset, riwayat, dan karyawan.

Sistem akan menyusun seluruh struktur dan data yang Anda miliki saat ini menjadi sebuah file `.json`. File ini sangat penting dan bisa digunakan untuk memulihkan (restore) server kapan pun diperlukan.

{% csrf_token %}

*Pilih SQL jika Anda ingin melakukan import langsung via phpMyAdmin/MySQL.

Informasi Penting

  • Simpan file backup ini di tempat yang sangat aman (seperti Google Drive atau Flashdisk eksternal) dan hindari membagikannya ke pihak luar.

  • Lakukan backup secara rutin (minimal seminggu sekali) terutama jika Anda sering menambahkan unit atau karyawan baru ke dalam sistem.

  • Untuk melakukan restore, berikan file ini kepada Teknisi IT yang memelihara sistem untuk dimuat ulang menggunakan perintah loaddata.
